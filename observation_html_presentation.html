教學亮點一

從觀念到實作：解析 HTML 語法

從觀念到實作：解析 HTML 語法

釐清觀念 · 拆解語法
  • 釐清觀念：HTML（超文字標記語言）用來組織架構並呈現網頁內容，並非程式語言，而是描述網頁結構的標記系統。
  • 拆解語法：每個網頁元素由「起始標籤」<p>、「內容」與「結束標籤」</p> 三部分組成，形成一對標籤包裹的結構單元。
  • 巢狀結構：標籤可層層嵌套，如同大綱層級，培養學生先想清楚架構再動手撰寫的習慣。
江老師以生活化比喻說明標籤如同「容器」，讓抽象語法變得具體可理解。

實作應用：常用 HTML 標記練習

動手做 · 即時回饋
  • 標題層級：運用 <h1>～<h6> 建立文件標題與段落層次。
  • 嵌入圖片：使用 <img> 插入圖片，認識 src、alt 等屬性意義。
  • 超連結：以 <a> 建立連結，連結網頁內外部資源。
  • 課堂節奏：講解 → 示範 → 學生練習 → 巡視指導，確保每位學生都能跟上。

學生專注理解標籤結構，並實際輸入 HTML 語法進行練習。

02

教學亮點二

工具輔助：所見即所得的網頁編輯

工具輔助：NVU 所見即所得編輯

降低門檻 · 視覺化學習
  • 軟體介紹：導入 NVU（Nvu）全自由開放的圖形化網頁編輯器，無需付費授權，適合校園推廣。
  • 直覺操作：利用「所見即所得」（WYSIWYG）特性，將程式碼與畫面即時對應，減少初學挫折感。
  • 雙軌並進：學生可切換原始碼檢視，對照剛學的 HTML 語法，加深「操作—語法」的連結。
圖形化介面讓學生先「看得見成果」，再回頭理解標籤意義，有效承接 HTML 入門單元。

結合應用：語法 × 工具完成網頁

任務導向 · 合作學習
  • 學生靈活結合 HTML 基本語法與 NVU 視覺化介面，快速完成簡單網頁。
  • 小組討論排版與內容，培養溝通與共識建立能力。
  • 教師桌邊巡視，即時排除操作疑問，維持學習動能。
  • 完成作品後的成就感，有助於後續進階網頁設計學習。

展現 NVU 排版實作，或老師在桌邊協助解決軟體操作問題的互動。

觀課反思與教學成長

策略分析 · 課綱呼應
  • 教學策略成功：將抽象的「文字式標記語言（HTML）」結合「圖形化介面工具（NVU）」，有效降低初學者認知負荷，提升學習動機。
  • 呼應科技領域精神：不只熟悉工具操作，更培養運用科技解決問題與數位創作的能力，契合課綱「資訊科技應用專題」學習目標。
  • 觀課收穫：「先理解結構、再借助工具、最後產出作品」的教學脈絡，值得納入自身備課參考。

未來建議與展望
